# mcserver

TO RUN THE SERVER YOU MUST:

Install docker desktop

Run the server using

```shell
docker compose up -d
```

Make sure your keys are properly set in .env

You'll need a playit.gg account and a curseforge account.

TO PLAY:

Install the modpack

(all the mods 10)

Join the server at the link specified in playit.gg (DO NOT SHARE IT PUBLICLY).
